# SkyFire 5.4.8 Modules

[English](README.md) | [Русский](README_RU.md)

A collection of modules and scripts I've ported or adapted for
[ProjectSkyFire 5.4.8](https://github.com/ProjectSkyfire/SkyFire_548).

I'm mostly a React/JavaScript developer who somehow ended up digging through
C++, SQL and WoW emulator internals. This repository is where I keep the ports
that survived the process.

This is a hobby project. It is not an official ProjectSkyFire repository, and
things may occasionally be broken, incomplete, or held together by questionable
decisions.

## Compatibility

The modules in this repository target:

- ProjectSkyFire 5.4.8
- [ProjectSkyfire/SkyFire_548](https://github.com/ProjectSkyfire/SkyFire_548)

Compatibility with TrinityCore, AzerothCore, other SkyFire branches, or other
WoW emulator cores is not guaranteed unless explicitly stated by a module.
