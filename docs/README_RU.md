# Модули для SkyFire 5.4.8

[English](README.md) | [Русский](README_RU.md)

Коллекция модулей и скриптов, которые я портировал или адаптировал под
[ProjectSkyFire 5.4.8](https://github.com/ProjectSkyfire/SkyFire_548).

Вообще я в основном React/JavaScript-разработчик, который каким-то образом
докатился до C++, SQL и внутренностей эмулятора WoW. Здесь лежат порты,
пережившие этот процесс.

Это хобби-проект, а не официальный репозиторий ProjectSkyFire. Что-то здесь
может быть недоделано, сломано или держаться на решениях сомнительной
инженерной ценности.

## Совместимость

Модули в этом репозитории рассчитаны на:

- ProjectSkyFire 5.4.8
- [ProjectSkyfire/SkyFire_548](https://github.com/ProjectSkyfire/SkyFire_548)

Совместимость с TrinityCore, AzerothCore, другими ветками SkyFire и другими
эмуляторами WoW не гарантируется, если обратное явно не указано для конкретного
модуля.
